# Circles: Semantic Manifold Visualization

Circles is an interactive topological playground designed to visualize the high-dimensional geometry of human language as captured by Large Language Models (LLMs). 

### The Concept
Words and phrases are not static points; they are "manifolds" or "membranes" of meaning. In this app, these concepts act like interactive rubber-band simulations in 2D and 3D. 

### The Philosophical Hypothesis
The project aims to visually prove that "individual perspectives"—the tiny islands of truth people cling to—are merely specific, restricted 3D camera angles of a much larger, interconnected global manifold of shared human concept representation.

### Core Features
* **Top-Down 2D View:** Concepts represented as interactive, elastic membranes.
* **3D Manifold Rendering:** Smooth isosurface generation (Marching Cubes) surrounding token activation clusters.
* **Perspective Locking:** Demonstrate how shifting camera matrices changes the "appearance" of a concept while the underlying data remains constant.
